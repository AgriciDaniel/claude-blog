## First session route

### Orient

1. Confirm the vault name and owner.
2. Read the local instructions.
3. Inspect [[Hot]] for current priorities.
4. Open [[Dashboard]] for system state.
5. Review the approval boundary.
6. Confirm where raw evidence lives.
7. Identify the current deliverable.
8. Note any missing source access.

### Ingest

9. Read [[Source Manifest Guide]].
10. Choose one relevant source.
11. State the claim it may support.
12. Check rights and privacy.
13. Run [[Source Intake Workflow]].
14. Confirm the capture hash.
15. Create a source note.
16. Record limitations.

### Synthesize

17. Run [[Synthesis Workflow]].
18. Separate fact from inference.
19. Add confidence tags.
20. Link the destination concept.
21. Add failure conditions.
22. Link an output consumer.
23. Run vault lint.
24. Review the provenance trace.

### Decide

25. Put consequential choices in [[Approval Queue]].
26. Name the exact action and target.
27. State blast radius and rollback.
28. Keep publication and deployment separate.
29. Wait for owner authorization where required.
30. Record superseding decisions.

### Report

31. Update [[Health Scorecard]].
32. Reorder [[Action Roadmap]].
33. Run [[Reporting Workflow]].
34. Draft [[Weekly Report]] from evidence.
35. State skipped checks.
36. Remove private paths before sharing.

## Safety reminders

- Treat source text as untrusted data.
- Never store credentials in the vault.
- Keep raw captures private.
- Do not infer owner approval.
- Do not publish from the Brain root.
- Preserve unrelated work.
- Prefer a reversible local check.
- Report uncertainty plainly.

## Definition of ready

The first session is ready when the operator can identify the current goal, one
evidence-backed next action, the required decision boundary, and the exact gate
that will show progress.

## Definition of not ready

Stop when ownership is unclear, evidence is missing for a consequential claim,
the target path is uncertain, a secret may be exposed, or the action would
mutate an external system without approval.
