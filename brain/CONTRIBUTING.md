# Contributing

Keep changes small, sourced, and verified.

- Read `CODEX.md`, `README.md`, and `docs/PRODUCT_BOUNDARIES.md`.
- Update tests before release-affecting behavior changes.
- Do not commit credentials, client data, or copied third-party content with
  unknown license.

## Community

Use public project Discussions for design questions and contributor support:
https://github.com/AgriciDaniel/claude-blog/discussions.
Use public Issues for reproducible defects and scoped change proposals:
https://github.com/AgriciDaniel/claude-blog/issues.
