## Google and web-platform corrections

Primary sources were re-opened instead of trusting prior summaries:

- [PageSpeed Insights API](https://developers.google.com/speed/docs/insights/v5/get-started): CrUX field data in PSI is planned for removal; use the CrUX APIs for field data.
- [Soft Navigations API](https://developer.chrome.com/docs/web-platform/soft-navigations): current Chrome documentation says rollout begins with Chrome 151, replacing the old Chrome 139 trial wording.
- [Organization structured data](https://developers.google.com/search/docs/appearance/structured-data/organization): Google’s documentation, not Schema.org alone, is the authority for Google Search behavior.
- [Google AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide): standard Search foundations apply to AI features, and Google does not require special AI files or markup.
- [Google Search Status Dashboard](https://status.search.google.com/products/rGHU1u87FJnkP6W2GwMi/history): official rollout dates and durations replaced rounded or unsupported update descriptions.
- [June 2026 spam incident](https://status.search.google.com/incidents/YUX1peHev5a4fkxLDiUQ): the incident page supports global and all-language scope plus the June 24 to June 26 rollout, but not unsupported technique-specific claims.
- [Google Ads API release notes](https://developers.google.com/google-ads/api/docs/release-notes): current v25 client compatibility drove the 31.2.0 minimum and the 31.4.0 lock.
