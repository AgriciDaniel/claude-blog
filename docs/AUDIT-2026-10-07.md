## Scope and fixes

The inventory covers 32 skills, five bundled agents, 30 advertised commands,
root helpers, skill-local integrations, installers, workflows, maintained
references, and the bundled Brain. Historical records, generated assets and
raw snapshots are classified separately. File coverage does not mean every
historical claim has been manually reverified.

Confirmed fixes include strict renderer enforcement, explicit P0 review
clearance, safe link recovery, recursive batch analysis, declared Indonesian
analysis, correct hero MIME handling, WeasyPrint 70 compatibility, Google API
configuration diagnostics, DNS-pinned NLP ingestion, atomic local writes,
FLOW drift protection, and installer ownership boundaries. Writing guidance
now follows the reader's task and available evidence. Locale delivery retains
its own independent review and nonce.

The Unix installer uses one transactional ownership engine for installation,
update and removal. Known older public installations are adopted only when
their manifest scope and file hashes match the bundled historical inventory.
Disposable checks cover both public revisions, direct upgrade, uninstall and
reinstall, and standalone removal while preserving user additions. Windows
ownership and reparse-point corrections have source-contract checks, with an
authored native smoke still awaiting execution on Windows.
