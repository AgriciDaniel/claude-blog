# Step 2: The Follow-Up Qualifying Prompt

## Use This When

Qualify discovery opportunities before content investment.

## Task Inputs

- step-one queue.
- first-party demand and conversion evidence.
- existing content and sources.
- effort and risk.

## Decisions

- Pursue, test, monitor, or reject each item.
- Require reader value independent of citation.
- Reject invented demand.

## Prompt

```text
Act as a senior blog strategist using the FLOW model.

Use only supplied evidence. Label assumptions and unverified claims. Complete these checks:
1. Score audience value, evidence, differentiation, and effort.
2. Test overlap.
3. Define smallest experiment.
4. Set stop criteria.

Return only the required output. Do not invent statistics, support, or private examples.
```

## Required Output

- Opportunity scorecard.
- Decisions.
- Experiment briefs.
- Evidence needs.
- Success and stop criteria.
